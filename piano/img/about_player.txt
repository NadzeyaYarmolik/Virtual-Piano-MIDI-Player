Данная часть проекта представляет собой полнофункциональный MIDI-плеер с продвинутыми возможностями управления звуком и визуализацией активности каналов. Плеер интегрирован с основной MIDI-системой приложения, обеспечивая единый контроль над воспроизведением и обработкой звука. Он обеспечивает точную синхронизацию MIDI-событий, корректную обработку контроллеров и плавное переключение между треками. Визуальная обратная связь через панель каналов позволяет пользователю визуально отслеживать активность каждого инструмента в составе MIDI-композиции.


Основной функционал плеера:
• Загрузка и воспроизведение стандартных MIDI-файлов с поддержкой форматов .mid и .midi
• Управление плейлистом с возможностью сортировки по названию, длительности или порядку загрузки
• Три режима воспроизведения: повтор всего плейлиста, повтор текущего трека и без повторения
• Регулировка скорости воспроизведения (0.5x, 1x, 2x) без потери тональности
• Визуализация активности 16 MIDI-каналов в реальном времени через панель светодиодов

Управление воспроизведением:
• Перемотка трека на соответствующую позицию используя полосу прогресса
• Клавиши 0-9 для быстрой перемотки на соответствующую позицию (0 = 100%)
• Стрелки влево/вправо для перемотки на ±10 секунд
• Полнофункциональный транспортный контроль: play, pause, stop, previous, next
• Регулировка звука при помощи ползунка с кнопкой для отключения/включения звука

Продвинутое управление каналами:
• Индивидуальная регулировка громкости для каждого из 16 MIDI-каналов
• Режим Solo Channel для изоляции конкретного канала
• Функция mute для временного отключения каналов
• Визуальное отображение текущего инструмента на каждом канале
• Полный сброс всех каналов к значениям по умолчанию

Особенности интерфейса:
• Контекстное меню для каждого канала с быстрым доступом к настройкам
• Отображение подробной информации о канале: инструмент, громкость, состояние
• Поддержка трех тем оформления: Modern, Paper и Water
• Адаптивный интерфейс с анимированными кнопками и плавными переходами
• Всплывающие подсказки с информацией о файлах и состоянии воспроизведения

Управление плейлистом:
• Добавление файлов (до 20 МБ)
• Контекстное меню для удаления отдельных треков
• Функция перемешивания плейлиста в случайном порядке
• Очистка всего плейлиста с подтверждением
• Отображение длительности каждого трека и общего прогресса
• Возможность сортировки плейлиста по названию, длительности или порядку загрузки


Техническая реализация состоит из следующих частей:

• Плеер использует QMidiFile для обработки MIDI-файлов и QMidiOut для отправки команд на внешние устройства. Воспроизведение работает на точном таймере с интервалом 16 мс, что обеспечивает плавное звучание, а временные метки конвертируются между тиками и миллисекундами для точной синхронизации событий. Обработка MIDI-событий включает анализ типов сообщений (NoteOn, NoteOff, ProgramChange, ControlChange), где NoteOn с нулевой velocity конвертируется в NoteOff. Активные ноты отслеживаются через QSet пар канал-нота для предотвращения залипаний.

• Громкость канала на выходе состоит из двух компонентов: мастер-громкость и индивидуальные настройки каналов. Значения преобразуются из диапазона 0-100% в MIDI-формат 0-127 с коэффициентом 1.27. Режим Solo Channel сохраняет предварительные состояния громкости, возвращая их при его отключении. Визуализация каналов использует сигнально-слотовую систему. Панель LedsPanel отображает активность через кастомные кнопки с контекстным меню управления. Обновления интерфейса выполняются в главном потоке с целью избежать мерцания. Скорость воспроизведения регулируется без изменения питча благодаря адаптивному таймеру.

• Перемотка реализуется через сложный алгоритм сохранения/восстановления состояний. Сохраняются громкости, контроллеры и инструменты, затем воспроизводится последовательность событий до целевой позиции для корректной инициализации. Плейлист управляется с помощью нескольких контейнеров: используется QList для путей, std::vector для файлов, QList для длительностей. Сортировка сохраняет текущий трек через indirect indexing. QSettings отвечает за сохранение и применение таких настроек, как режимы воспроизведения, сортировки, громкости, темы оформления и позиция воспроизведения.

Наконец, этот MIDI-плеер сочетает в себе функционал секвенсора с понятным интерфейсом, тем самым обеспечивая полный контроль над многоканальным звуком. Перед использованием убедитесь, что выходное MIDI-устройство правильно подключено и активно
